连接 GitHub 仓库

站点内容和图片都存在你自己的仓库里，这个后台只是帮你改它。填一次，会记在这台设备的浏览器里。

  1. 打开 github.com/settings/personal-access-tokens/new
  2. Token name 随便写；Expiration 选 90 天或更长
  3. Repository access 选 Only select repositories → 只勾 sc
  4. Permissions → Repository permissions → Contents 设为 Read and write
  5. 点 Generate token，把 github_pat_… 开头的那串复制过来
